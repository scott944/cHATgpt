Measurement Input (DSL)

Scott's 6-Step DSL Reference 
# PRE-STEP: Grid Setup (1m squares at 1:100)
GRID X A=0 B=1000 C=2000 D=3000
GRID Y 1=0 2=1000 3=2000
SCALE 1000              # mm per major square

# STEP 1: Purple dots (perimeter corners)
PERIMETER D/2, G.6/2, K.2/2.8

# STEP 2: Blue dots (internal walls)
INTERNAL G.6/4, H.8/4, K/6.8

# STEP 3: Green dots (exterior elements)
EXTERNAL G.6/1.4, J.6/1.4

# STEP 4: Join the dots (walls)
WALL D/2-G.6/2 thickness=110
# All walls MUST be H or V (no diagonals!)

# STEP 5: Wall thickness applied automatically
# (110mm external, 90mm internal)

# STEP 6: Dimension confirmation
DIM D/2-G.6/2 offset=800

# STEP 7: Doors & windows
DOOR D/2-G.6/2 offset=900 width=820
WINDOW K.2/2.8-K.2/6.8 offset=600 width=1200 sill=900

# Rooms
ROOM "BED 1" walls=... level=Ground
LEVEL Ground=0 First=2700

# Decimal grid refs:
# G.4 = column G + 400mm (2 small squares)
# K.2 = column K + 200mm (1 small square)
# Format: Column/Row e.g. G.6/16.4

# Legacy format also supported:
# WALL A1-B1 thickness=110
Perimeter Internal External
